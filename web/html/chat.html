This is not a chatbot with the database in its prompt. It is an LLM given a fixed set of functions it may call. Which LLM is a config choice - LLM_BASE_URL in compose points at whichever endpoint you like, local or hosted, and no code changes either way.

When you ask something, the model does not answer straight away - it replies with a tool call, like search_alerts(camera_id=3, since_minutes=60). The server runs that function, which is ordinary Python with an ordinary SQL query, and hands the rows back. Only then does the model write a sentence.

So it can never invent a number: every figure below came out of Postgres. It also cannot see the camera images, and it cannot answer anything the system does not store - there is no "why", no maintenance notes, no history of who did what.

It does know which cameras are being analysed and with which detection models, so it can explain an absence - if nothing is being reported, it can tell you whether the camera is idle or simply running weights that have no class for what you asked about.
